# Hotel Listing

An ASP.NET 5 Web API for hotel listings, built while following the "Ultimate ASP.NET 5 Web API Development Guide" course.

## About The Project

This project is a hotel listing REST API built with ASP.NET 5, organized with controllers, models, repositories and Entity Framework Core migrations, with a docker-compose.yml for supporting services.

## Built With

- C# / ASP.NET 5 Web API
- Entity Framework Core
- Docker Compose

## Getting Started

### Prerequisites

- .NET SDK (the version pinned in global.json)
- Docker (optional, for the services in docker-compose.yml)

### Running the API

Open HotelListing.sln in Visual Studio, or from the command line:

```bash
dotnet run --project HotelListing
```
